# ShieldLens - Frontend Client

This directory contains the web user interface for ShieldLens, built using Next.js 15, strict TypeScript schemas, and zero external visual UI components to enforce clean and rapid-loading.

## Quick Local Launch

Make sure your local Python backend is actively running on port `8000` first, then execute these commands in this directory:

```bash
# 1. Restore compilation dependency trees
npm install

# 2. Boot up the local development interface stream channel
npm run dev
```

The web will immediately be operational locally at `http://localhost:3000`.
